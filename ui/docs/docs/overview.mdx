## Key Features

- **Chat Completion** - Generate responses using our language models
- **Text-to-Speech** - Convert text to natural-sounding audio with Kokoro-TTS
- **Speech-to-Text** - Transcribe audio files with Whisper-STT accuracy  


## Available Models

- **Jan-nano** - Compact 4B parameter model optimized for tool use and function calling
- **Kokoro-TTS** - High-quality text-to-speech synthesis
- **Whisper-STT** - Advanced speech recognition and transcription
